# 📚 Wayhunter Obsidian Graph — Start Here

Welcome broo 💜 This vault connects the **uploaded** Wayhunter source documents using Obsidian links, without changing the original PDFs or rules documents.

## Start here

1. Open [[Wayhunder Home]] — main interactive project map.
2. Open [[wayhunder]] — short project overview.
3. Click a module e.g. [[Game]] or [[Coins System]] to follow related source documents.
4. Press `Ctrl + P` → **Open graph view** → Enter to view connected notes.
5. If you cannot see PDFs as dots, open the graph **Filters** and enable **Attachments**. The Markdown overview notes will remain connected either way.
