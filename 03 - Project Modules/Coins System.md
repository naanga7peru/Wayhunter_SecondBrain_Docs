# Coins System / Wallet / Vouchers

Main: [[Wayhunder Home]] · Rule reference: [[Current Rules - Source Guide]]

## Earn

- New verified account: +100 once.
- Approved Hunter submission: +200 once.
- Approved Game creator: +100 once.
- One eligible, admin-verified Game winner: +100 once.

## Wallet and demo redemption

- Level bar advances for every **2,000 lifetime earned Coins**.
- Need **at least 10,100 spendable Coins** to request the academic demo 10,000-Coin voucher.
- Pending = reserve 10,000; Admin approval = debit once; rejection = release.
- Voucher sample image, unique code and QR are demo output; real cash payout not implied.
